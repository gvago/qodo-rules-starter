Exercise 1 · Evidence

Find one to three real findings

The compiler accepts this code and the happy-path run prints success. Use Claude, Codex, or your usual agent. Ask it to inspect the code, then verify every claim against the exact line and return contract.

#include "sensor_buffer.h"
#include <stdlib.h>

/* Ingest a burst of raw readings coming off the CAN receive path. */
int sensor_ingest(sensor_buffer_t *buf, const uint16_t *raw, size_t n) {
    uint16_t *scaled = malloc(n * sizeof(uint16_t));

    for (size_t i = 0; i < n; i++) {
        scaled[i] = (uint16_t)(raw[i] * 4u);
        sensor_buffer_push(buf, scaled[i]);
    }

    free(scaled);
    return SENSOR_OK;
}
